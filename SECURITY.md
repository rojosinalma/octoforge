# Security policy

## Reporting a vulnerability

Report a vulnerability in a tool privately through that tool's GitHub Security Advisories:

- [octotally](https://github.com/rojosinalma/octotally/security/advisories/new)
- [octohatchery](https://github.com/rojosinalma/octohatchery/security/advisories/new)
- [octowarden](https://github.com/rojosinalma/octowarden/security/advisories/new)

For a problem in Octoforge itself (the app, the checks, the workflows, the member list), use [this repository's advisory form](https://github.com/rojosinalma/octoforge/security/advisories/new).
Do not open a public issue. You will get an acknowledgement within a week.

The app handles GitHub credentials. Reports about a credential reaching a log line, the database,
an API answer or the disk are especially welcome.

## Supported versions

The latest release of the app is supported. Each tool
documents its own supported versions.
