# Security policy

## Reporting a vulnerability

Octoforge itself contains no application code. Report a vulnerability in a tool privately through that
tool's GitHub Security Advisories:

- [octotally](https://github.com/rojosinalma/octotally/security/advisories/new)
- [octohatchery](https://github.com/rojosinalma/octohatchery/security/advisories/new)

For a problem in this repository (the checks, the workflows, a pinned submodule pointing at a
vulnerable version), use [this repository's advisory form](https://github.com/rojosinalma/octoforge/security/advisories/new).
Do not open a public issue. You will get an acknowledgement within a week.

## Supported versions

Only the submodule pointers on `main` are supported. Each tool documents its own supported versions.
